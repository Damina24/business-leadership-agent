# Client data

Place the client's real data here so the officers can ground advice in it:

- Sales records, invoices summaries, price lists (CSV, XLSX)
- CRM or customer exports (remove anything the team does not need)
- Financial statements, budgets, cost sheets
- Marketing and website analytics exports
- Existing plans, pitch decks, policy documents

Only share what you have the right to share. This folder is confidential and is excluded from Git by default.
