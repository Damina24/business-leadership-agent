# /monthly-review

Use the `chief-of-staff` skill. Follow `shared/context-protocol.md`.

1. Read `clients/<slug>/outputs/decision-log.md`. List every decision that is Implemented or In progress, and every one past its review date.
2. For each, ask the owner for the actual result, or find it in new data files. Record the actual result and the lesson in the log (Rule 10). Mark whether the original estimate was too high, too low, or about right.
3. Update the KPI scorecard from the latest data (`chief-growth-officer`, `revenue-growth-manager`, `head-of-growth`, `business-development-manager`). Show trend against targets.
4. `chief-operating-officer`: capacity and quality check against current load.
5. `chief-financial-officer`: cash position and forecast accuracy.
6. `risk-compliance-officer`: any new risks, complaints, or rule changes.
7. `chief-growth-officer`: what to continue, stop, or change next month. Reprioritize with the scoring model.
8. Produce a one-page executive growth review and save it as `clients/<slug>/outputs/reports/YYYY-MM-monthly-review.md`.
9. Update `profile.md` if facts have changed (prices, team, goals, authority).
